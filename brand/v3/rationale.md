# PocketCCD 字标 v3 · 基于提供的 pocketCCD_logo.png

## 保留了什麼

- **字形本身**：浑圆的书写衬线、P 的长尾、k 的收笔，这些都是原图最好的部分，一个像素没重画。
- **两段结构**：`Pocket` 暖白 + `CCD` 琥珀，CCD 作为右下角的小标签。
- **暖色关系**：奶白配琥珀，而不是品牌原来的中性暖白 + 琥珀。

## 改掉了什麼

| 原图 | 现在 | 原因 |
| --- | --- | --- |
| 斜切高光 / 浮雕 | 纯平色 | 品牌约定零渐变零阴影；浮雕缩小后变脏 |
| 深蓝色底 `#111426` | 品牌黑 `#0B0C0A` | 统一产品底色，图标与界面同色 |
| CCD 用原图土黄 | 品牌琥珀 `#F0AD3D` | 与 App 内强调色一致 |
| 右下角「豆包 AI 生成」水印 | 裁掉 | 不能进正式资产 |
| 边缘毛刺、压缩噪点 | 中值 + 形态学清理 | 放大/缩小都不出现脏边 |
| 只有深底一版 | 深底 + 纸色底两版 | 商店页、发票、浅色场景都要用 |

## 交付物

- `wordmark-dark.png` / `wordmark-light.png`：约 1282 × 507，纯平，透明背景可直接叠加
- `avatar-1024.png`：方形头像版（字标居中、留 11% 边距）
- `brand-sheet.png`：深底 / 浅底 / 头像三种用法
- `compare.png`：原图 vs 优化后
- `reference-cropped.png`：去掉水印的原图存档

## 两条限制，必须说清楚

1. **这是描出来的位图，不是矢量。** 现在约 1282px 宽，App 内、商店页、社交头像都够用；
   印刷、巨幅、或要改字距时，需要按这份形状重新勾一遍矢量路径（我可以做，但要用钢笔工具逐点修）。
2. **它不能当 App 图标。** 横向字标塞进正方形会缩到看不清。图标要单独做，三个选项：
   - 保留现在的「P + 琥珀镜头环」几何标（和字标风格不同，但小尺寸最稳）；
   - 用这个字标里的 P 做图标（碗口需要补成闭合弧线，图上现在是被裁平的）；
   - 只放「P」字母，不做图形修饰（最省事，也最像 Kapi / ism 的路线）。

## 建议

字标用这份 v3；图标先用现有的几何标，等字标定稿后再决定要不要统一风格。
确认后我把 v3 接进 `brand/` 与商店素材，并把 `scripts/generate_logo.py` 的说明同步更新。
