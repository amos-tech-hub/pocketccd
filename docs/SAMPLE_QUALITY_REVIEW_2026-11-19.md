## 0. 结论先行

1. **昨天的 P0 方向问题确认已修**：49 张全部 `orientation=1`，横竖构图都正立，日期戳不再歪 —— 这批没有任何一张需要旋转。
2. **A7 的红色保护有效**：直射光下的肤色 R/G 从昨天的 **2.04** 降到 **1.28 / 1.36**，进入产品门槛 1.15–1.35；阴影里的 1.71 属于「偏黄」而不是「荧光红」，观感可接受。
3. **今天的样张是「同一场景、四个 look」的对照拍法**（6 组），这是最理想的比较方式，比昨天的跨场景聚合可靠得多。
4. **最大的问题从 A7 转移到了 C1**：同机位长椅上高光裁切 **8.19%**（产品门槛 <2%），肤色 R/G **1.84**（A7 1.71、直射光 1.28–1.36），天空被推到青色（同场景 skyG/B 0.91 vs A7 0.95 只差一点，但长椅场景 8% 裁切是硬指标）。
5. **A8 / N2 在白天暴露出设计场景之外的表现**：A8 暗部压死（blk4 最高 **14.1%**，黑位成片、暗角重）；N2 整体青蓝偏移 + 噪点最高（相对噪声 1.68，A7 1.39），白天用就是「青色滤镜」。
6. **颗粒仍然是所有 look 的共同短板**：100% 看，阴影与肤色都有可见彩噪块，N2 最重。手机屏尺寸（商店截图 1290×2796）看不出来，100% 或大屏看就露。
7. 商店/社媒可用性：**A7 白天场景可用**（推荐 5610、5616、5653、5697）；C1 / A8 / N2 这批不适合直接出图。

## 4. 问题清单（按严重度）

### P1 · C1 高光裁切超标
- 证据：长椅 **8.19%**、黄叶树 4.08%、码头 2.66%（产品门槛 `<2%`，见 `Research/CompetitiveImagingBenchmark.md`）。
- 现参数（`CCDLook.swift`）：`exposureEV +0.10`、`contrast 1.22`、`whiteClamp 0.97`、曲线顶点 0.965、`saturation 1.04`。
- 直接后果：白衣服、地砖、天空云底先于其它 look 死白；比对图里长椅场景最明显。

### P1 · C1 肤色偏品红
- 证据：皮肤 R/G 1.84（A7 直射光 1.28–1.36）。
- 现参数：`temperature 7200` + `tint −7`（向品红）+ `contrast 1.22`（逐通道）。
- 与产品定位冲突：C1 的包装是「bright, cool, clean skin」，现在「cool」做到了，「clean skin」没有。

### P1 · A8 暗部压死
- 证据：blk4 3.4–14.1%（高架 14.1%、黄叶树 10.6%），同场景 A7 只有 0.1–1.2%。
- 现参数：`blackClamp 0.0` + `shadowLift 0.0` + `lumaContrast 1.18`。这是为硬闪设计的「闪光没照到的地方就该黑」，白天逆光/树荫就变成大片死黑。

### P2 · N2 白天青蓝偏移 + 噪点最高
- 证据：同场景天空 G/B 0.53（高架）vs A7 0.68；R−B 聚合 −0.136；相对噪声 1.68 为四 look 最高。
- 现参数：`temperature 8200` + `tint +32`（为钠灯/LED 夜街补偿）。它不是白天用的 look，白天出现「青色滤镜」不算 bug，但用户会随手拍。

### P2 · 颗粒仍是共同短板
- 证据：100% 裁切下阴影、肤色都有彩噪块（`docs/assets/samples-1119/crops100.jpg`）；N2 的蓝色通道噪声最明显（`blueNoise 1.36`）。
- 说明：昨天已把合成 `grain` 降过一轮，剩下的主要是手机高 ISO 的传感器噪点，靠 `noiseReduction` 单点加大只会涂抹。

### P2 · A7 白天发灰、暗部偏脏
- 证据：blk4 0.0–1.2%（黑位被抬起来），`shadowLift 0.08` + 曲线起点 0.018；高架/湖面整体像蒙一层灰。
- 好处是天空和云干净；代价是「CCD 味」变成「灰味」。

### P3 · 日期戳配色各 look 不同
A7 橙、A8 红、C1 白、N2 绿 —— 若是有意的品牌行为可忽略；若用户以为是「随机」，需要说明。

## 6. 建议下一步（未改代码，等确认）

按性价比排序：

1. **C1 先修白点**：`whiteClamp 0.97 → 0.94`、曲线顶点 `0.965 → 0.945`，并把 `exposureEV +0.10 → +0.04`。目标是长椅场景裁切从 8.19% 降到 2% 以下，同时保持「最亮」的定位。
2. **C1 肤色**：`tint −7 → −2`、`temperature 7200 → 6800`。先只动这两项，重拍长椅+白衣验证 R/G 能否进 1.5 以内。
3. **A8 黑位**：`blackClamp 0.0 → 0.004`、`shadowLift 0.0 → 0.04`（只救暗部，不动 lumaContrast，保住「硬」）。验收：高架场景 blk4 从 14.1% 降到 <6%。
4. **N2**：不动参数，改为**产品层面**——选 N2 时提示「适合夜间/弱光」，或在白天自动建议 A7。真要动就只收 `tint +32 → +20`，青色会掉一档，但会伤钠灯街的暖补偿，建议先拍一组夜间样张再定。
5. **颗粒**：如果要压，方向是「暗部分亮度降噪 + 彩噪去饱和」，不是继续加全局 `noiseReduction`（昨天已验证会涂抹）。
