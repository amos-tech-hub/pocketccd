## 7. 真机验收清单（按优先级）

1. **闪光恢复**：故意制造一次闪光拍照超时（遮住镜头/快速取消），随后拍普通夜景，确认不再整体发黑。
2. **Dual Memory**：从设置页进入，前后摄各一张；再试同时双录路径（若机型支持）。
3. **配对**：两台手机连接 → 离开配对页 → 对方按快门，确认本机不再响应；连续点 Connect 不再出现幽灵邀请。
4. **Moment**：前置自拍确认视频已镜像；对比 16:9/1:1 静帧与视频构图（已知仍有差异，记录样片供下一批修）。
5. **手势快门**：开启后观察预览帧率与发热，确认 `preview-stats.json` 的 `renderAvgMs` 未明显上升。
6. **StoreKit**：沙盒购买 → 断网重启 → 确认仍解锁；退款/撤销 → 确认上锁；弱网下不要出现「付费用户被上锁且下次仍锁」。
7. **备份**：模拟索引损坏（删除 manifest）→ 启动收养 → 导出备份 → 新装导入，确认照片和文件名都在。
8. **提审**：Archive 后上传，确认不再出现 ITMS-91053；核对 App Store Connect 隐私问卷与三类 reason API 一致。
9. **卷满失败**：把卷填满后拍 Moment，确认结果页重开时视频仍可预览/分享（不再指向已删文件）。
10. **卷页**：临时把条目数做到 > 容量（或改 UserDefaults 的 rollCapacity），确认打开卷页不崩。
