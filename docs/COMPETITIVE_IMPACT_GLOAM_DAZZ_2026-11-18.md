# Gloam / Dazz 影响评估与命名简化结论

日期：2026-11-18（Asia/Shanghai）
数据源：iTunes Search / Lookup API（US、CN 店，当日抓取）、Sensor Tower / Storelift 公开页、App Store 产品页、公开评测
适用对象：PocketCCD（未上架；`store/release/APP_REVIEW_AND_PRIVACY.md` 仍列有 ASC 内购与归档上传两项阻塞）

---

## 0. 结论先行

1. **Gloam 不是「又一个滤镜 App」，它抢的是我们最贵的两样东西：色彩叙事和价格锚。** 它在中文区 3 个月内做到摄影免费榜 #26、畅销榜 #22，买断价 ¥58/$7.99，比我们计划的 $9.99 低一档。
2. **Dazz 依然是天花板和比价参照**：CN 118.5 万评分、US 11.8 万评分，第三方估月流水约 $90 万，订阅 $9.99/月、$69.99/年。它证明品类有钱，也证明「订阅疲劳」是我们的机会。
3. **我们的差异只剩三样，而且都不在「色彩」上**：多帧直闪模式、卷/接触印样、双机配对。Gloam 有单张闪光、有日期戳，但没有这三样。
4. **名字可以简化，但只能简化写法，不能简化掉 `CCD` 这个词**：`PocketCCD → Pocket CCD`（加空格）即可；降到 `Pocket` 或 `CCD` 都会输。搜索分词已验证 camelCase 不影响索引，所以加空格纯粹是「读得出来」，不是 SEO 动作。

## 2. Gloam 的产品结构（它凭什么起来）

- **四条相机线，命名全部借真实机型**：`T3`（Contax T3 式胶片色彩）、`CCD12`（Canon G12 式 CCD 影调）、`GRD`（理光 GR 街头 + 黑柔）、`U2`（便携胶片 + 日期戳）。每条线内含多档色彩配置。
- **日期戳、机身边框、拍完可换机重新冲印**（保留底片后自由切换相机）。
- **明确不做导入**：「均需实拍」是它的纯度声明，也是它的功能缺口。
- 没有卷/冲洗/接触印样，没有双机配对，没有多帧闪光模式，未见视频。
- 单张闪光可用（评测提到夜拍开闪「不会有糊脸感」）。

**它卖的是「色彩」，我们卖的是「行为」。这两件事在货架上会互相踩。**

## 3. 影响拆解

### 3.1 被吃掉的（4 条，逐条给判断）

| 我们原本的卖点 | Gloam 之后 | 判断 |
|---|---|---|
| 「比 Dazz 更真实、更清透的胶片色彩」 | 中文社媒已经把这个叙事写完了（「不是平替，是取代」「比 Dazz 更清透」），且它有真实机型名做可信度锚点 | **失效**，不要在色彩上正面竞争 |
| 「只拍不导，保留拍摄的仪式」 | Gloam 直接用「不能导入」换纯度；我们反而有导入功能，讲这条会显得像功能少 | **弱化**，改讲「拍完一卷才看得到」 |
| 「买断、无订阅」 | Gloam 也是买断（¥58/$7.99），这条从「反 Dazz 武器」降级为「品类标配」 | **降级** |
| 「CCD 这个词我们占得早」 | 中区 `CCD相机` 104,649 评分、`ProCCD` 70,165、`Dazz` 118 万；美区 `ccd cam` top3 中位 2,317 评分 —— 词被占满，但**搜索需求真实存在** | **必须保留在名字里** |

### 3.2 仍然成立的（Gloam 和 Dazz 都没有）

1. **多帧直闪模式**：Flash Party（三连闪）/ Flash Pair（环境+闪光）/ Flash Sequence（环境+闪光+反应）。Gloam 只有单张闪。
2. **卷与接触印样**：24 张一卷、延迟冲洗、方形/Story 印样、回执卡。Gloam 无卷，Dazz 无卷。
3. **双机配对**：两台 iPhone 同时按下快门生成双联图。两家都没有。
4. **2 秒 Pocket Moment**：视频抽帧，Dazz 有视频但走的是 DV/VHS 复古路线，不是「一张照片的现场」。

### 3.3 六个层面的具体影响

| 层面 | 影响 | 动作 |
|---|---|---|
| **搜索** | `ccd`/`复古相机` 在 CN 被 10 万+ 评分产品压住；US `ccd cam` 竞争度仅 2,317 评分（可打），`flash camera` 202（最好打） | 先打 `flash camera` / `digicam` / `digital camera 2000s`，`ccd` 只做索引不做主攻 |
| **价格** | $9.99 vs Gloam $7.99，单位价值上我们 3 台相机 vs 他们 4 线多档 + 拍后换机 | 不降价。先把「Gloam 没有的三件事」做进首屏；若首月解锁 <0.8% 再调功能分层 |

## 4. 名字能不能简化

### 4.1 先看三个「能不能」

| 候选 | 搜索实测（US，当日） | 判断 |
|---|---|---|
| `PocketCCD` | 无同名 App；搜索 `pocket ccd` 首屏是 FotorGear(1,594)、TOK CAM(515)、Pocket Digicam(0)、CCD CAM(950) | 可用，但「Pocket + CCD」组合已被挤满 |
| `Pocket` | `Pocket - AI Personal Assistant` 8,066 评分、`Pokémon TCG Pocket` 70 万评分、`Pocket FM` 27.8 万 | **拿不到名称位**，且丢掉品类信号 |
| `CCD` | `CCD — Y2K Digicam Camera` 已存在；CN `CCD相机` 104,649 评分；纯通用词不可注册 | **等于放弃品牌** |

### 4.2 一个被证伪的担心：连写会不会影响搜索

实测 App Store 搜索会对 camelCase 自动拆词：

- 搜 `pocketcasts` 与 `pocket casts` → **返回完全相同的列表**（Pocket Casts 均列第一）
- 搜 `pccd` → 第一屏是 `ProCCD`（`Pro`+`CCD` 被拆开命中）

所以 `PocketCCD` 已经在索引 `pocket` 和 `ccd` 两个词，**改名不带来任何搜索收益**。加空格只是为了「读得出来、打得对」。

### 4.3 建议

**改写法，不改词：`PocketCCD` → `Pocket CCD`。**

- 商店名：`Pocket CCD — Digicam Camera`（28/30）
- 副标题：`Direct flash · 2000s look`（25/30，不变）
- 关键词：沿用 `ccd,film,grain,pocket,retro,party,y2k,disposable,compact,vintage,photos,receipt`（79 B）
- 中文名：`Pocket CCD：CCD 闪拍相机`；中文副标题：`直闪人像 · 2003 数码质感`
- 成本：未上架时几乎为零（水印文案已经是 `POCKET CCD`，有空格，改名后反而一致）；上架后改名要新版本 + 排名重置
- 不接受：`Pocket`（占名）、`CCD`（通用词）、`PCCD`（不可读，搜 `pccd` 首屏是 ProCCD）

### 4.4 更值得改的命名问题：三台相机叫 `A7 / C1 / N2 / A8`

这是比 App 名更亏的地方。Gloam 用 `T3 / GRD / U2 / CCD12` —— 全是真实机型，用户一眼就知道「这是理光味」「这是 G12 味」，可信度直接借来。我们的字母数字串没有任何语义，用户在货架上无法建立「这台相机是什么性格」。

已实施（2026-11-18，不动内部型号，只加外显性格词）：

| 内部 | 外显 | 场景 |
|---|---|---|
| POCKET A7 | `A7 · Warm 2003` / 暖调 2003 | 暖肤色、室内聚会 |
| POCKET A8 | `A8 · Party Flash` / 派对闪光 | 直闪主力 |
| POCKET C1 | `C1 · Cold Sharp` / 冷调锐利 | 冷调、街拍 |
| POCKET N2 | `N2 · Green Grain` / 绿影颗粒 | 夜景噪点、绿影 |

落点：相机条第二行、付费墙相机卡、Camera Guide 详情、VoiceOver（`accessibilityValue` 读名字，`accessibilityHint` 读功能描述）。

## 5. 本周可执行（按优先级）

1. **名字加空格**：ASC 名称、`CFBundleDisplayName`、网站标题、截图文案、IN-APP 关于页（约 2 小时，未上架所以免费）。
2. **首屏三张截图换成** Flash Party / Roll / Pairing（素材已有，1 天）。
3. **定价维持 $9.99**，把「Gloam 没有的三件事」写进描述前 3 行，第一行写「It actually fires the flash」。
4. **给三台相机加性格词**（文案改动，代码不动）。
5. **中区延期到英文区跑通之后**，且只走内容，不走 ASO。

## 6. 反向观点与停损

- 反向：如果 12 个月内「闪 + 卷 + 双机」做不出留存与自发传播，Gloam 的「色彩 + 低买断价」会持续压我们的价格，$9.99 站不住，最终要么降价要么并入色彩竞争（必输）。
- 别做：跟进 Gloam 的相机数量；二次改名（Nightroll 已回滚一次，改名成本 > 收益）；在 `CCD` 单词上做品牌文章。
