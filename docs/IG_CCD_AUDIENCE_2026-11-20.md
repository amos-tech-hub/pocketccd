# Instagram 上 CCD/胶片用户在发什么、想要什么

日期 2026-11-20。来源：Gloam 的小红书/App Store 讨论、Dazz CCD CAM 指南、Grazia/Adorama 的 digicam 趋势报道、NOMO/Kapi 的商店评论。用于决定 Pocket CCD 改什么。

## 1. 他们在发什么

1. **夜晚直闪人像**——Dazz 把 CCD CAM 直接定位成“夜晚闪光女王”：乳白瓷肌、强对比、轻微过曝。这是 TikTok/IG 上最核心的一类内容。
2. **街头/日常快照**——不完美、柔焦、颗粒、低饱和。Adorama 的定义：比现代手机更软的焦点、近距直闪、不完美的快照感。
3. **带日期戳/边框的“老照片”**——日期打印、胶片边框本身就是分享货币。
4. **IG carousel / 拼图**——ProCCD 直接把“40+ 复古相机 + carousel/collage 模板”做成卖点。
5. **机型身份内容**——“韩女/爱豆同款 CCD 型号合集”这类笔记，卖的是“用哪台相机”的身份，不是参数。
6. **教程/前后对比**——“CCD + 闪光灯怎么拍”（后置闪光、俯拍、放大镜头显脸小）。

## 2. 他们为什么发

- **怀旧/Y2K**：闪光、轻微过曝、低像素，是 2000 年代名人文化的视觉记忆。
- **对抗过度计算**：手机把照片修得太干净，CCD 的“不完美”反而真实。
- **身份表达**：理光 GR、T3、U2 这些型号名，是品味标签。
- **低门槛**：新华网的原话——“操作简单”，不需要专业技术。
- **社交货币**：日期戳、边框、型号让照片“像作品”，而不是随手拍。

## 3. 他们想要什么

| 需求 | 证据 |
|---|---|
| 直出、快 | NOMO 评论：按下快门要等几秒才能拍下一张；快门延迟 |
| 不订阅/买断稳 | Kapi：自动扣费、退款难、被骂 scam；Gloam：58 元买断，担心换机丢失 |
| 无广告/水印 | VizoCam 把 “No Watermark” 写进卖点 |
| 实时预览准 | Gloam 评论：“开盲盒”，弱光/大光比难预判 |
| 导入相册 | Gloam 最大缺陷之一：只能实拍，不能导入 |
| 闪光灯 | 夜晚直闪是 CCD 审美的核心 |
| 颗粒/柔焦/色差 | NOMO 好评：corner softness、chromatic aberrations |
| 日期戳/边框 | 分享货币，Gloam/ProCCD 都有 |
| 简单 | 新华网：CCD 翻红因为不设门槛 |

## 4. 他们抱怨什么（我们的机会）

- **Gloam**：不能导入、预览不准（开盲盒）、界面“梦回 iOS8”、买断换机有风险、只有 iOS。
- **NOMO**：处理慢、快门延迟、登录问题。
- **Kapi**：订阅自动扣费、广告、退款难。

**这三条正好是 Pocket CCD 的强项**：实时预览、导入相册、无订阅、快门快。这不是“我们也做胶片”，而是“Gloam 的色彩 + 我们的不盲盒”。

## 5. 对 Pocket CCD 的判断

1. **默认路径不要换**：首屏保持直闪（A8），因为“夜晚直闪人像”是 IG 上最核心的内容，也是我们现在的差异点。
2. **成片方向对了**：刚把肤色 R/G 从 1.85 压到 1.35、天空 G/B 0.63→0.82，正好落在 IG 用户要的“乳白肌 + 青蓝天空”。
3. **日期戳/边框要更显眼**：这是分享货币，不是装饰。建议默认开日期戳，边框一键开。
4. **胶片线是加分项，不是核心**：需求存在，但用户更在意快、直出、不订阅。1.1 做“负片”第 5 台即可，不换默认。
5. **机型故事 > 参数**：用户记的是 T3/U2/GRD，不是“1.12 对比度”。我们的 A7/A8/C1/N2 可以加一句“原型机”叙事（2003 暖调卡片机 / 直闪派对机 / 冷调锐机 / 钠灯夜机），但**名字不改**。
6. **carousel 不必自己做**：ProCCD 做了模板，但我们已经有 4:5 裁切 + 边框 + 日期戳，足够发单图/轮播。

## 6. 建议改什么（按优先级）

1. **默认日期戳打开**（现在是可选），边框保持可选——分享货币优先。
2. **A8 直闪再“瓷”一点**：提亮中间调、压红，目标 R/G 1.4–1.5、高光不裁切。这是 IG 上最容易被转发的样张。
3. **机型叙事**：四台相机各加一句原型描述（已有 sceneTag，可扩成一行故事），降低“这四台有什么区别”的疑问。
4. **1.1 负片第 5 台**：复用 halation/颗粒，加暗部基色和高光肩部，不换默认。
5. **营销对比**：主打“实时预览、能导入、不订阅”——直接打 Gloam 的三条差评。
