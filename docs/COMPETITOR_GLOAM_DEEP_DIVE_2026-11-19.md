## 2. 产品拆解

### 2.1 技术路线：从 RAW 起步，而不是从成片滤镜

公开评测与官方文案一致：Gloam 读取 iPhone 的 **RAW 数据**，自己做色彩映射、影调调整、颗粒处理，再输出 JPG。它保留类似“数字底片”的中间数据，拍完之后还能重选预设、调影调与白平衡。

这条路线和 Dazz / ProCCD 那一代「在已处理 JPG 上盖滤镜」有本质区别：**它抢的是传感器输出，不是成片**。代价是慢——拍完要等处理，不适合连拍。

### 2.2 相机线：用真实机型名做可信度锚

- `T3`（胶片色彩，参考 Contax T3 与 X5 扫描的复古胶片）
- `CCD12`（参考 Canon G12 的 CCD 影调）
- `GRD`（理光 GR 味，负片/正片 + 黑柔）
- `U2`（傻瓜机胶卷，SP3000 扫描风格）

每条线内含多档色彩配置，带日期打印与机身边框。**它的命名不是产品线，是借来的可信度**：用户一眼知道这是理光味还是 G12 味。

### 2.3 明确不做的事

| 不做 | 用户反应 |
|---|---|
| 导入相册照片 | 差评高频项：「买了终身会员，能不能改进下」 |
| 实时预览 | 差评最高频：「按快门像开盲盒」「要先拍完回去看」 |
| 视频 | 多条评论求加 |
| 安卓 | 官方 8/20 发过防山寨警告，明确暂无 |
| 连拍 | 处理要等，自己承认不适配高速抓拍 |

### 2.4 已知缺陷（来自评论，非推测）

- **更新必须卸载重装**，重装会丢 App 内照片（1 星）
- **买断后仍提示订阅**，尤其跨区账号（中国用户用美区 ID）需反复“恢复购买”
- 弱光噪点大、大光比容易过曝
- iPhone 18 Pro / Duo 适配不全（焦距显示错、光圈无手动）
- 开发者对 bug 反馈不回应（1 星点名“很傲慢”）

## 3. 增长路径（可复用的部分）

1. **小红书首发**：8/13 官方帖「热乎的：Gloam 相机上线了」→ 近 2000 赞、1400+ 评论；
2. **金句型 UGC 自传播**：「Gloam 毁了我的胶片梦」单条 2000+ 赞；「有了 Gloam，灭了我想入理光的念头」；
3. **把二手机涨价变成购买理由**：理光 GR / 富士 X100 二手价上行，Gloam 以 ¥58 卖“平替色彩”；
4. **媒体跟进**：什么值得买、少数派风格长文、iPhone 18 Pro 摄影横评把它列为三选之一；
5. **口碑的两面**：所有爆款内容都在夸色彩，所有差评都在骂交互缺失——**这正是它的天花板**。

## 4. 价格与转化

- ¥58 买断 / $7.99；年费 ¥38（部分文章写 ¥35）
- 换算：一个用户 ≈ 一卷胶卷钱（它自己的社区话术）
- 以 10–50 万下载/月、买断价推算，$80K 左右月流水意味着转化在 **1–3%** 区间，且客单低
- **它证明了买断制在中文市场成立**，也证明单靠色彩上限不高：要更高 ARPU 只能靠订阅或场景化（活动/聚会）

## 5. 对 Pocket CCD 的含义

### 5.1 它占住的（不要正面打）

| 它占住的 | 我们的应对 |
|---|---|
| 「胶片色 / 清透感」的叙事与口碑 | 不与之比色彩；我们讲**直闪行为**，那是 RAW 色彩映射补不出来的 |
| 「真实机型名」的可信度 | 已用性格词（Warm 2003 / Party Flash…）补位，但**不要**改用真实机型名（商标风险） |
| 中文摄影圈的新品光环 | 中区第二阶段不靠 ASO，靠内容，且不抢「胶片色」这个词 |

### 5.2 它漏掉的（我们的正面战场）

| 它的差评 | 我们的现状 |
|---|---|
| 没有实时预览 | **有**（24fps 同算法预览） |
| 不能导入 | **有**（PhotosPicker） |
| 没有视频 | **有**（Pocket Moment 2 秒） |
| 没有卷/冲洗 | **有**（Pocket Roll 24 张 + 接触印样） |
| 单机位 | **有**双机配对 |
| 更新丢照片 | 我们的数据在 Application Support + 原片归档，不随重装丢 |

**这六条直接构成一条对比文案**：「Gloam 让你拍完才知道是什么样；Pocket CCD 让你按下快门之前就知道。」

### 5.3 值得借鉴的三件事

1. **「数字底片」要讲出来**。我们有 `Original Frame Archive`（原片归档），能力和它的“底片重渲”一样，但**没有一个用户知道**。它把这个概念讲成了卖点，我们连名字都没露。
2. **相机名要能唤起真实机型**。它用 T3/GRD/U2（有商标风险但有效），我们用性格词；下一步可以在描述里加一句“A7 的灵感来自 2003 年的家用 CCD 卡片机”这类**叙述性**锚点，不碰商标。
3. **单点功能做到极致就能起量**。它只做“色彩直出”，就进了摄影畅销 #22；我们的单点应该是“直闪 + 一卷”，别摊薄。

### 5.4 时间窗

Gloam 美区只有 12 条评分，**尚未出海**。但它有 5 个语言、145 MB 包体和成熟的内容方法，出海只是选择问题。

**窗口判断：6–9 个月。** 在那之前我们要么在美国区立住「直闪相机」这个词，要么就只能等它回来用同一套打法压我们。
